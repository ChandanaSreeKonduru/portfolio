Scan It Know It — Scan a product. Know what's in it. That's it.

A free, no-signup, no-ads, privacy-first product information tool — you scan a label, you get plain-language ingredient analysis, AI-powered nutritional breakdown, and a local chatbot to ask follow-up questions. No shopping recommendations. No cloud uploads. No account. Just information. Built from scratch in 3 weeks as a community project in Omaha, NE.

Phase 08 Challenges, Learnings & V2 Modifications Ongoing
Challenge 1 — Gemini latency on complex labels

Initial Gemini calls spiked on dense multi-panel labels (nutrition + ingredients + allergens). Fixed with image pre-processing (resize + crop to label region before API call) and local Ollama fallback for repeat products already in Chroma. Response time stayed under 5s.

Challenge 2 — Hallucination on niche products

RAG returned low-confidence results for niche supplement brands absent from USDA CSV. Fixed with HITL routing — below 0.80 confidence the app shows a "We're not certain" card instead of guessing. Users preferred honesty over a confident wrong answer.

Learning 1 — Agentic coding = PM superpower

PRP templates fed to Cursor reduced scaffolding from days to hours. The PM's role shifted from writing implementation specs to writing precise AI behaviour prompts — a directly transferable skill for any AI product role.

Learning 2 — "No recommendations" is a feature

Every tester appreciated the absence of shopping suggestions. In a market where every app is trying to monetise attention, pure information without agenda became the strongest trust signal. Privacy-first and ad-free = the actual product value.

V2 modifications planned — next iteration
V2 · Fully offline vision model

Replace ephemeral Gemini with a fully local vision model (llava or moondream via Ollama) — zero cloud dependency, 100% offline after install. The PWA + service worker architecture already supports this swap without a rebuild.

V2 · Personal health profile (local-only)

User defines their conditions once (diabetes, nut allergy, gluten-free) — stored locally in the browser, never sent anywhere. Every Safe/Check badge then personalises to their profile. The RAG query context would update per scan automatically.

V2 · Expanded product categories

Current dataset covers food + basic cosmetics. V2 adds: medications (OTC drug interaction flags), cleaning products (chemical safety), and clothing (fabric + dye allergens). Each category gets its own curated open-dataset CSV added to Chroma.
